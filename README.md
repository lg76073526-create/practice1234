# 알바영어

외국인 손님이 카운터에 섰을 때, 시험 영어 대신 바로 입으로 말할 수 있게 연습하는 앱입니다. 업종을 고르면 그 매장에서 쓰는 문장만 남습니다.

치킨집 예시처럼, “No bone?” 대신 “Would you like that boneless or bone-in?”을 말하도록 고칩니다.

## 실행

브라우저에서 `index.html`을 열면 됩니다. 별도 설치나 서버 계정은 없습니다.

소리 내어 대화의 마이크는 크롬에서 아래처럼 로컬 주소로 열어야 동작합니다. 파일을 직접 열면 브라우저가 마이크를 막아, 영어로 적어서 보내는 칸으로 바뀝니다.

```bash
ruby -run -e httpd . -p 8765
```

그다음 크롬에서 `http://127.0.0.1:8765/index.html` 을 열고, 마이크 허용을 눌러 주세요.

## 화면

하단 탭은 홈, 업종, 내 알바, 메뉴입니다.

- **홈** — 오늘 쓸 한 문장, 이어서 하기, 상황 문장, 소리 내어 대화, 출근 카드
- **업종** — 요식업, 의류, 기타 중에서 매장을 고릅니다
- **내 알바** — 마지막으로 연 업종의 문장과 연습
- **메뉴** — 로그인, 계정 정보, 학습 기록, 주간/야간, 앱 정보

업종 안에서는 상황 문장을 읽고, **글로 연습**하거나 **소리 내어 대화**할 수 있습니다. 가상 손님은 미리 만든 대사를 브라우저 음성으로 읽고, 사용자의 대답이 어색하면 더 분명한 문장을 보여 줍니다.

## 업종

| 분류 | 업종 |
| --- | --- |
| 요식업 | 카페, 빵집, 치킨집, 술집, 식당 |
| 의류 | 옷 가게, 신발 |
| 기타 | 편의점, 마트 |

## 저장

계정, 익힌 상황, 주간/야간 설정은 이 브라우저의 `localStorage` 키 `alba-english`에만 남습니다. 서버로 보내지 않습니다. 계정을 지워도 학습 기록은 남습니다.

## 구성

HTML, CSS, JavaScript만 사용합니다.

```text
index.html    앱 껍데기
css/style.css 화면
js/data.js    업종, 문장, 연습 대사
js/app.js     화면 이동, 채점, 음성, 계정
```

문장과 연습 대사를 바꿀 때는 `js/data.js`를 수정합니다.
